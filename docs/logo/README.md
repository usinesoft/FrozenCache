# FrozenCache logo

| | File | Status |
|---|---|---|
| <img src="ice-crystal.svg" width="48" alt=""> | `ice-crystal.svg` | **Current logo.** A rounded hexagon cut like a crystal. Used by the dashboard as its header logo and favicon (copied to `FrozenCache/Dashboard/public/logo.svg`). |
| <img src="ice-cube.svg" width="48" alt=""> | `ice-cube.svg` | Alternative: an isometric ice cube, a block of frozen data. |
| <img src="frozen-stack.svg" width="48" alt=""> | `frozen-stack.svg` | Alternative: a storage stack whose top disk is ice. Draft: the drips under the frozen disk need refining. |

All three use the same ice-blue palette (`#e3f5ff` → `#8fd3fb` → `#3f93e0` → `#1f5fb0`) and are drawn on a
64 × 64 grid. The wordmark next to the logo is "**Frozen**Cache" in Fira Sans: "Frozen" semibold in slate
(`#2f4550`, light mode) or near-white (`#e8eef2`, dark mode), "Cache" light in ice blue (`#2a78d6` / `#6aaef0`).

A snowflake was deliberately avoided: a blue snowflake for a data product is too close to the trademarked logo of
Snowflake Inc.
